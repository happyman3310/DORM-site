# WAYN database setup (PostgreSQL)

Этот проект пока фронтендовый, но для будущего бэкенда подготовлена схема БД,
соответствующая текущим сущностям интерфейса (пользователь, чекпоинты,
направления, критерии).

## Быстрый старт

1. Убедитесь, что PostgreSQL установлен и запущен.
2. Создайте базу данных (пример):

```bash
createdb wayn
```

3. Примените схему:

```bash
psql -d wayn -f db/init.sql
```

## Что создаётся

- `users`
- `checkpoints`
- `checkpoint_areas`
- `directions`
- `direction_criteria`

При необходимости расширяйте схему по мере появления бэкенда.
