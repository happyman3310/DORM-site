# WAYN MVP — Детальный список задач

## 0. Подготовка и рамки (обязательно)
- [ ] Зафиксировать пороги интерпретации: X (разрыв), Y (минимум), Z (динамика).
- [ ] Утвердить лимиты тарифа Free (число выборов, глубина истории).
- [ ] Согласовать точные тексты для статусов профиля (школа/вуз/работа/другое).
- [ ] Проверить список жизненных областей (7 шт.) и закрепить порядок отображения.

## 1. Frontend (MVP UI/UX)
### 1.1 Базовая структура
- [ ] Сверстать AppShell (top bar + bottom nav).
- [ ] Подключить тёмную/светлую тему с переключателем.
- [ ] Настроить типографику, сетку, отступы, стеклянные карточки.

### 1.2 Экраны
- [ ] Auth (login/register + age/status).
- [ ] Dashboard (Where Are You Now + интерпретация + активные выборы).
- [ ] Checkpoint form (шкалы 0–10 + комментарии).
- [ ] Directions list (активные выборы).
- [ ] Direction create (название, описание, результат, срок, критерии).
- [ ] Direction review (ожидание vs реальность).
- [ ] History (графики динамики).
- [ ] Pricing (Free/Pro заглушка).

### 1.3 Визуализация
- [ ] Радар/столбцы (placeholder → реальный график позже).
- [ ] Карты перекосов/слабых зон (визуальные индикаторы).
- [ ] Компоненты статусов и прогресса.

## 2. Backend (этап после UI)
### 2.1 Auth
- [ ] Регистрация/логин по email + пароль.
- [ ] Минимальный профиль (возраст, статус).

### 2.2 Данные
- [ ] LifeAreas (фиксированный список).
- [ ] Checkpoints + LifeAreaScores.

### 2.3 Правила интерпретации
- [ ] Разрыв между зонами > X → подсветка.
- [ ] Зона < Y → предупреждение.
- [ ] Рост/падение ≥ Z → динамика.
